# React + TypeScript + Vite

  ## Today's Weather

  A responsive weather app built with React and TypeScript. It shows the current weather for a city using the OpenWeather API.

  ## Features

  - Search weather by city and country
  - Search history with re-search and delete
  - Error message for invalid city or country
  - Light and dark theme switcher
  - Responsive on mobile, tablet and desktop

  ## Tech Stack

  React, TypeScript, Vite, Tailwind CSS, Motion

  ## Getting Started

  1. Install dependencies:

     ```bash
     npm install
     ```

  2. Create a `.env.local` file in the project root:

     ```
     VITE_OPENWEATHER_API_KEY=your_api_key_here
     ```

  3. Start the app:

     ```bash
     npm run dev
     ```
